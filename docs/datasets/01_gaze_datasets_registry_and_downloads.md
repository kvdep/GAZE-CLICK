# Реестр открытых датасетов оценки направления взгляда и статус локальной загрузки

## 1. Введение и системные требования к хранилищу

Настоящий документ регламентирует структуру, метрические характеристики, источники загрузки и статус локального развертывания датасетов для задач трехмерной оценки направления взгляда (3D Gaze Estimation) и слежения за точкой фиксации на экране (Point-of-Gaze).

Все внешние исследовательские базы данных размещаются на внешнем съемном накопителе microSD **`E:\ВКР\`** для предотвращения исчерпания емкости системного твердотельного накопителя `C:`.

### Текущее распределение дискового пространства:
* **Диск `E:\` (microSDXC):** $112.22\text{ ГБ}$ свободно из $116.5\text{ ГБ}$.
* **Диск `C:\` (System NVMe):** $41.2\text{ ГБ}$ свободно из $926.0\text{ ГБ}$.

## 3. Детальный анализ каждого датасета и взаимная ортогональность

### 3.1. Gaze360 (MIT CSAIL / Toyota Research Institute)
* **Официальный репозиторий:** [`https://github.com/erkil1452/gaze360`](https://github.com/erkil1452/gaze360) (переведен автором в статус archived / read-only).
* **Причина недоступности серверов MIT (`gaze360.csail.mit.edu`):**
  Сервер возвращает статус `HTTP 403 Forbidden` с телом:
  ```html
  <p>You don't have permission to access this resource.Server unable to read htaccess file, denying access to be safe</p>
  ```
  Это системный сбой прав доступа веб-сервера Apache к файлам конфигурации `.htaccess` на диске CSAIL, заблокировавший весь домен для глобальных пользователей с марта 2026 года (по данным Wayback Machine CDX, последняя успешная фиксация `200 OK` датирована январем 2026 г.).
* **Китайское зеркало Baidu Netdisk:**
  - URL раздачи: `https://pan.baidu.com/s/1sP8FaZe4IfA6zb40r8gr0Q` (код извлечения: `4wgk`).
  - Файл: `/视线估计数据集/Gaze360.rar`.
  - Метаданные: `fs_id = 192157053644997`, размер $1\,675\,127\,412$ байт ($1.56\text{ ГБ}$), MD5: `89f59c775h2c1fb56a20c070c6101b78`.
  - Содержит предобработанные нормализованные кропы лиц и глаз для моделей GazeTR и L2CS-Net.
* **Официальный полный датасет ($28.45\text{ ГБ}$, $30\,548\,756\,480$ байт):**
  Обнаружено открытое побитовое зеркало оригинального архива MIT CSAIL на Hugging Face:
  - Репозиторий: `immediately/Gaze360-split`
  - Структура разделения на 6 частей по 5 ГБ:
    1. `Gaze360.tar.partaa`: $5\,368\,709\,120$ байт
    2. `Gaze360.tar.partab`: $5\,368\,709\,120$ байт
    3. `Gaze360.tar.partac`: $5\,368\,709\,120$ байт
    4. `Gaze360.tar.partad`: $5\,368\,709\,120$ байт
    5. `Gaze360.tar.partae`: $5\,368\,709\,120$ байт
    6. `Gaze360.tar.partaf`: $3\,705\,210\,880$ байт
    Сумма: $\sum_{i=1}^6 \text{size}_i = 30\,548\,756\,480$ байт (ровно $28.45\text{ ГБ}$, первый заголовок TAR `metadata.mat`).
  - Скрипт загрузки с поддержкой докачки: [`mvp/experiments/download_gaze360_splits.py`](file:///c:/Users/jack_/MAIN/ВУЗ/ВКР/mvp/experiments/download_gaze360_splits.py).

    ```cmd
    tar -xf E:\ВКР\Gaze360\Gaze360.tar -C E:\ВКР\Gaze360\
    ```
* **Состав скачанной локальной разметки:**
  Архив `Gaze_txt_files.zip` ($132.6\text{ МБ}$) скачан с Hugging Face (`Morning5/Gaze360`) и полностью распакован в директорию `E:\ВКР\Gaze360\annotations\Gaze_txt_files`. Он включает **6 718 файлов разметки** по всем 238 субъектам (`p001` $\dots$ `p238`), содержащих временные метки, позу головы и 3D векторы направления взгляда.

### 3.2. Columbia Gaze Data Set (Columbia CAVE)
* **Прямой URL:** `https://www.cs.columbia.edu/CAVE/databases/columbia_gaze/columbia_gaze_data_set.zip`
* **Объем:** $2\,378\,561\,401$ байт ($2.22\text{ ГБ}$).
* **Скрипт загрузки:** [`mvp/experiments/download_columbia_gaze.py`](file:///c:/Users/jack_/MAIN/ВУЗ/ВКР/mvp/experiments/download_columbia_gaze.py) (потоковая загрузка с докачкой Range HTTP).
* **Статус загрузки, верификации и распаковки:** Загрузка полностью завершена за 2914.8 с. Контрольная сумма и целостность архива верифицированы модулем `zipfile.testzip()` (CRC32 тест пройден без сбоев). Распаковка полностью завершена за 280.3 с в `E:\ВКР\ColumbiaGaze\Columbia Gaze Data Set\` ($5\,882$ файла изображений $5184 \times 3456$ по всем 56 субъектам, исключая служебные файлы macOS).
* **Ортогональность к Gaze360:**
  1. Выборка полностью независима: 56 участников (32 мужчины, 24 женщины в возрасте 18–36 лет, 21 носит корригирующие очки).
  2. Фиксированная дискретная сетка: 5 положений головы ($-30^\circ, -15^\circ, 0^\circ, +15^\circ, +30^\circ$) и 21 точка фиксации взгляда по горизонтали и вертикали.
  3. Профессиональная оптика Canon Rebel T3i обеспечивает эталонную резкость радужки без артефактов интерполяции панорамных линз Ladybug5.

### 3.3. MPIIFaceGaze (Max Planck Institute for Informatics)
* **Прямой URL:** `https://huggingface.co/datasets/doanhlt/degraded-gaze-mpiifacegaze/resolve/main/MPIIFaceGaze.h5`
* **Объем:** $4\,948\,673\,290$ байт ($4.61\text{ ГБ}$).
* **Скрипт загрузки:** [`mvp/experiments/download_mpiifacegaze.py`](file:///c:/Users/jack_/MAIN/ВУЗ/ВКР/mvp/experiments/download_mpiifacegaze.py).
* **Статус загрузки и верификации:** Загрузка полностью завершена за 4974.0 с. Объем файла на диске: ровно $4\,948\,673\,290\text{ байт}$. Магические байты HDF5 (`b'\x89HDF\r\n\x1a\n'`) подтверждены. Файл доступен для извлечения нормализованных кропов лиц $224 \times 224$ и истинных 3D-векторов.
* **Ортогональность к Gaze360:**
  1. Доменная специфика: данные собраны в реальных сценариях работы за ноутбуком в течение 12 месяцев (15 участников, 45 000 кадров).
  2. Дистанция до камеры составляет $40-70\text{ см}$ (ближнее поле, рабочее место оператора), в то время как Gaze360 снимался с дистанции $1.5-3.0\text{ м}$ (дальнее поле).
  3. Формат `MPIIFaceGaze.h5` содержит предобработанные нормализованные кропы лица $224 \times 224$ и глаз вместе с истинными 3D-векторами и положением экрана.

### 3.4. RT-GENE (Zenodo Record 2529036)
* **REST API:** `https://zenodo.org/api/records/2529036`
* **Объем:** $37.2\text{ ГБ}$ (35 TAR-архивов по 17 сессиям `s000` $\dots$ `s016`).
* **Ортогональность к Gaze360:**
  1. Единственный открытый датасет с миллиметровой разметкой взгляда в естественных подвижных условиях, полученной через встроенные в очки инфракрасные трекеры SMI ETG 2W ($60\text{ Гц}$).
  2. Содержит параллельные потоки с очками (`_glasses`) и с синтетическим устранением очков методами глубокого восстановления (Inpainting `_noglasses`).
