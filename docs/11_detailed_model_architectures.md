# Детальная спецификация архитектур моделей оценки направления взгляда

## Введение

Настоящий документ содержит исчерпывающее инженерное описание 27 верифицированных архитектур моделей машинного обучения для оценки направления взгляда (Gaze Estimation) и слежения за точкой фиксации на экране (Point-of-Gaze), опубликованных или размещенных в открытом доступе на платформах Hugging Face Hub, GitHub и ArXiv в 2016–2026 годах (с фокусом на период 2024–2026 гг.).

Все архитектуры ранжированы по единому строгому критерию:
$$\text{Метрика качества (наименьшая угловая ошибка } \mathcal{E}_{ang}\text{ в градусах)} \longrightarrow \text{Год публикации (от 2026 к 2024)} \longrightarrow \text{Размер обучающего датасета}.$$

Все представленные модели отфильтрованы по критерию автономного локального запуска на персональном компьютере:
- Исключены специализированные инфракрасные датчики (NIR/IR) и закрытые аппаратные комплексы.
- Исключены сверхтяжелые модели с объемом весов $> 1.5\text{ ГБ}$ (такие как ViT-Huge с 632 млн параметров), задержка которых на CPU превышает $150\text{ мс}$.
- Для каждой модели зафиксированы прямые ссылки на веса (Google Drive, Baidu Wangpan, Zenodo, Hugging Face Hub, GitHub Releases).

Для каждой архитектуры описаны:
1. Тип схемы: одностадийная или многостадийная с указанием точного числа стадий $N$.
2. Входные пространства и тензоры нормализации ($SO(3)$, PnP, 3D-нормализация камеры Sugano/Zhang).
3. Топология бэкбона (число слоев, каналы, фильтры, механизмы репараметризации или внимания).
4. Промежуточные представления и тензоры, извлекаемые на каждом этапе.
5. Компоненты сети: разветвление потоков (Disentanglement), блоки слияния (Cross-Attention, CCAF, Concatenation), регрессионные и классификационные головы.
6. Функции потерь с точными математическими формулами.
7. Вычислительная сложность, число обучаемых параметров, задержка вывода на CPU и GPU ($T_{inf}$), аппаратные ограничения.

## 1. PureGaze (Cheng et al., AAAI 2022 / HF: `akgulburak/gaze-estimation-diversity`, 2026)

```
[Вход: Лицо 224x224x3 BGR] ──► [Backbone ResNet-50] ──► [Латентный вектор f: 2048-d]
                                                                │
                               ┌────────────────────────────────┴────────────────────────────────┐
                               ▼                                                                 ▼
                  [Очищенные признаки f_g]                                          [Вспомогательные признаки f_u]
                               │                                                                 │
             ┌─────────────────┴─────────────────┐                                               │
             ▼                                   ▼                                               ▼
    [Gaze Head: MLP->2]                [GRL -> Discriminator D]                         [Decoder реконструкции]
    (Лосс взгляда L_gaze)              (Adversarial Loss L_adv)                         (Лосс реконструкции L_rec)
```

* **Ранг по метрике:** 1 (Абсолютный лидер эмпирического бенчмарка 9 сессий пользователя).
* **Метрика качества:**
  * Эмпирический бенчмарк 9 сессий: **$\mathcal{E}_{ang} = 1.85^\circ \pm 0.44^\circ$** (Медиана **$1.70^\circ$**, Мин **$1.32^\circ$**).
  * Корреляция с экранными координатами: **$R_x = +0.967$**, **$R_y = +0.895$**, коэффициент детерминации **$R^2 = +0.821$**.
  * Ошибка на экране ($D=600\text{ мм}$): **$19.5 \pm 4.7\text{ мм}$** (**$185.6 \pm 44.4\text{ px}$**).
  * Литературная ошибка на ETH-XGaze: **$3.88^\circ$**.
* **Размер датасета обучения:** ETH-XGaze ($1\,083\,492$ кадра, 110 чел.) + MPIIFaceGaze ($45\,000$ кадров, 15 чел.).
* **Схема исполнения:** Одностадийная при инференсе, двухпоточная самосостязательная при обучении.
* **Число стадий:** 1 (инференс) / 2 (обучение).
* **Входное пространство:** Кроп лица $224 \times 224 \times 3$, цветовое пространство **BGR**, масштабирование пикселей строго в диапазон $[0.0, 1.0]$ без вычитания среднего ImageNet.
* **Бэкбон:** ResNet-50 + блоки остаточной очистки ResGazeEs. Выход бэкбона — латентный вектор $\mathbf{f} \in \mathbb{R}^{2048}$.
* **Компоненты разделения (SA-Module):**
  * Вектор $\mathbf{f}$ расщепляется на очищенный компонент направления взгляда $\mathbf{f}_g$ и вспомогательный компонент внешности/освещения $\mathbf{f}_u$.
  * Слой обращения градиента (GRL) и дискриминатор $D$: подавляют чувствительность $\mathbf{f}_g$ к идентичности субъекта и фону.
  * Декодер реконструкции: восстанавливает входной кадр из $[\mathbf{f}_g \parallel \mathbf{f}_u]$ для сохранения геометрической полноты.
* **Выходная голова:** $\text{Linear}(C_g \to 2)$ по очищенному вектору $\mathbf{f}_g$. Выходной порядок: `angles[:, 0] = Yaw`, `angles[:, 1] = Pitch` в радианах.
* **Функция потерь:**
  $$\mathcal{L}_{total} = \mathcal{L}_{gaze}(\mathbf{y}, \hat{\mathbf{y}}) + \lambda_{rec}\mathcal{L}_{rec}(I, \hat{I}) + \lambda_{adv}\mathcal{L}_{adv}.$$
* **Параметры и производительность:**
  * Параметры инференса: $25.6\text{ млн}$.
  * Задержка инференса: **$13.63\text{ мс}$** на CPU (ONNX / PyTorch), **$3.2\text{ мс}$** на GPU.
* **Доступность весов:** Hugging Face `akgulburak/gaze-estimation-diversity` (`PureGaze/PureGaze_baseline_1.pt`).

## 2. GazeTR-Hybrid (Cheng & Lu, ICPR 2022 / HF: `akgulburak`, 2026 / GH: `yihuacheng/GazeTR`, 2024)

```
[Вход: Лицо 224x224x3 BGR]
        │
        ▼
[ResNet-18 Stages 1-3] ──► [Карта признаков: 7x7x512]
                                │
                      [Conv 1x1: 512 -> 256]
                                │
              [Flatten + Positional Encoding: 49x256]
                                │
                                ▼
               [6-слойный Transformer Encoder]
               [Multi-Head Self-Attention: 8 голов]
                                │
                                ▼
                    [Global Average Pooling]
                                │
                    [Linear: 256 -> 2 (Yaw, Pitch)]
```

* **Ранг по метрике:** 2.
* **Метрика качества:**
  * Эмпирический бенчмарк 9 сессий: **$\mathcal{E}_{ang} = 2.26^\circ \pm 0.47^\circ$** (Медиана **$2.03^\circ$**, Мин **$1.62^\circ$**).
  * Корреляция: **$R_x = +0.925$**, **$R_y = +0.890$**, $R^2 = +0.764$.
  * Ошибка на экране: **$23.8 \pm 4.9\text{ мм}$** (**$227.4 \pm 47.0\text{ px}$**).
  * Литературная ошибка: **$3.69^\circ$** на MPIIFaceGaze, **$3.88^\circ$** на ETH-XGaze.
* **Размер датасета обучения:** ETH-XGaze ($1.08\text{M}$) + MPIIFaceGaze ($45\text{k}$).
* **Схема исполнения:** Одностадийная гибридная сеть (CNN + Transformer Encoder).
* **Число стадий:** 1.
* **Входное пространство:** Лицо $224 \times 224 \times 3$, BGR, нормализация $[0.0, 1.0]$.
* **Бэкбон:** Первые 3 стадии ResNet-18 (Conv1, Layer1-3), извлекающие карту $7 \times 7 \times 512$.
* **Компоненты трансформера:**
  * Проекция $\text{Conv } 1 \times 1$ ($512 \to 256$) $\to$ развертка в $S = 49$ пространственных токенов.
  * Суммирование с двумерным обучаемым позиционным кодированием $\mathbf{E}_{pos} \in \mathbb{R}^{49 \times 256}$.
  * 6 слоев Transformer Encoder: 8 голов внимания (размерность $d_k = 32$), Pre-LayerNorm, FFN с расширением $256 \to 1024 \to 256$ и активацией GELU.
* **Выходная голова:** $\text{GAP} \to \text{Linear}(256 \to 2)$. Порядок осей: `[Yaw, Pitch]` в радианах.
* **Функция потерь:** $\mathcal{L}_{ang} = \arccos\left(\frac{\mathbf{g} \cdot \hat{\mathbf{g}}}{\|\mathbf{g}\|_2 \|\hat{\mathbf{g}}\|_2}\right)$.
* **Параметры и производительность:**
  * Параметры: $18.4\text{ млн}$.
  * Задержка инференса: **$15.21\text{ мс}$** на CPU, **$11.4\text{ мс}$** на GPU.
* **Доступность весов:** Hugging Face `akgulburak/gaze-estimation-diversity` (`GazeTR/GazeTR-baseline-1.pt`), Google Drive `https://drive.google.com/file/d/1WEiKZ8Ga0foNmxM7xFabI4D5ajThWAWj/view?usp=sharing`, Baidu Wangpan `https://pan.baidu.com/s/1GEbjbNgXvVkisVWGtTJm7g`.

## 3. EyeTAG (Lee, Ullah, Han, BMVC 2026 / GitHub: `peter8366/EyeTAG`, Октябрь 2026)

```
[Поток кадров: Лицо (224x224) + Глаза (112x112)] x T кадров
                        │
      ┌─────────────────┴─────────────────┐
      ▼                                   ▼
[Face ResNet-50 (VGGFace2)]       [Eye ResNet-18]
      │                                   │
      └─────────────────┬─────────────────┘
                        ▼
           [DSVE: Визуальные эмбеддинги e_t]
                        │
                        ▼
      [TAKE: Trajectory-Aware Kinematic Encoder]
  (Вход: разностная траектория Delta g_t = g_t - g_{t-1})
                        │
                        ▼
      [CCAF: Causal Transformer Decoder, T=48]
   (Кросс-внимание между кинематикой и признаками DSVE)
                        │
                        ▼
           [GVP: Head регрессии взгляда] ──► [g_t = (Yaw, Pitch)]
```

* **Ранг по метрике:** 3.
* **Метрика качества:**
  * Валидационный сплит EVE (`webcam_c`, 30 Hz): **$\mathcal{E}_{ang} = 2.56^\circ$** MAE.
  * Панорамный Gaze360: **$8.08^\circ$** Frontal ($|\text{Yaw}| \le 20^\circ$), **$9.12^\circ$** Semi-Frontal ($|\text{Yaw}| \le 90^\circ$), **$8.83^\circ$** Mean.
  * Временная стабильность: фиксационный джиттер $J = 3.68^\circ/\text{кадр}$, знаковое саккадическое смещение **$B = +0.05$** (практически нулевое недоведение взгляда при резком переводе взгляда), комплексный индекс нестабильности **$M = 1.87$** (лучший результат среди всех моделей).
* **Размер датасета обучения:** EVE ($12.3\text{ млн}$ кадров, 54 субъекта) + Gaze360 ($172\text{k}$ кадров) + VGGFace2 ($3.31\text{M}$ изображений).
* **Схема исполнения:** Многостадийная каузальная временная сеть ($N=3$).
* **Число стадий:** 3:
  1. *Стадия 1 (DSVE - Dual-Stream Visual Encoder):* независимое извлечение покадровых пространственных признаков лица и глаз.
  2. *Стадия 2 (TAKE - Trajectory-Aware Kinematic Encoder):* токенизация дифференциальной траектории взгляда $\Delta \mathbf{g}_t = \mathbf{g}_t - \mathbf{g}_{t-1}$.
  3. *Стадия 3 (CCAF - Cross-Attention & Causal Transformer Decoder):* кросс-внимание между визуальным и кинематическим потоками на окне из $T=48$ кадров.
* **Входное пространство:** Кроп лица $224 \times 224 \times 3$ и кропы обоих глаз $112 \times 112 \times 3$, RGB.
* **Бэкбоны:**
  * Лицо: ResNet-50, предобученный на VGGFace2 (`resnet50_ft_weight.pkl`).
  * Глаза: двухпоточный ResNet-18 с общими весами.
* **Компоненты сети:**
  * *TAKE:* преобразует кинематический дифференциал скорости перевода взгляда в компактный вектор размера $128$-d через двухслойный MLP.
  * *CCAF:* 4 слоя каузального декодера трансформера с маскированным вниманием (предотвращает заглядывание в будущие кадры).
  * *GVP:* выходная голова регрессии $\text{Linear}(256 \to 2)$.
* **Функция потерь:**
  $$\mathcal{L} = \mathcal{L}_{ang}(\mathbf{g}_t, \hat{\mathbf{g}}_t) + \lambda_{vel}\|\Delta \mathbf{g}_t - \Delta \hat{\mathbf{g}}_t\|_2^2.$$
* **Параметры и производительность:**
  * Параметры: $37.91\text{ млн}$.
  * Вычислительная сложность: $121.57\text{ GFLOPs}$ на окно из 48 кадров.
  * Задержка инференса: **$19.97\text{ мс}$** на окно ($0.42\text{ мс}$ на кадр в режиме потокового кэширования признаков DSVE).
* **Доступность весов:** Исходный код на GitHub `peter8366/EyeTAG`, веса бэкбона ResNet-50 VGGFace2 в открытом доступе на GitHub `cydonia999/VGGFace2-pytorch`.

## 4. STAGE (Swati et al., arXiv:2404.05215, 2024 / GitHub: `jswati31/stage`)

```
[Вход: Кадры видео EVE / Gaze360 / EYEDIAP]
                    │
                    ▼
       [SAM Image Encoder / ViT-B] ──► Пространственные признаки
                    │
                    ▼
     [Spatio-Temporal Attention Module]
                    │
                    ▼
   [Gaussian Process Personalization Head (GP)]
   (Few-shot адаптация по k калибровочным кадрам)
                    │
                    ▼
             [Углы взгляда (Yaw, Pitch)]
```

* **Ранг по метрике:** 4.
* **Метрика качества:**
  * Валидационный датасет EVE: **$\mathcal{E}_{ang} = 2.58^\circ$** MAE.
  * EYEDIAP: **$4.12^\circ$** (после адаптации по нескольким кадрам).
  * Gaze360 Frontal: **$9.43^\circ$**.
* **Размер датасета обучения:** EVE ($12.3\text{M}$) + Gaze360 ($172\text{k}$) + EYEDIAP.
* **Схема исполнения:** Двухстадийная архитектура ($N=2$).
* **Число стадий:** 2:
  1. *Стадия 1:* Пространственно-временное контрастивное кодирование признаков глаза на базе SAM / GazeCLR.
  2. *Стадия 2:* Байесовская персонализация на основе гауссовских процессов (Gaussian Processes) для привязки к конкретному пользователю.
* **Входное пространство:** Серия кропов глаз $112 \times 112 \times 3$.
* **Бэкбон:** ViT-Base (модифицированный Segment Anything Model image encoder) + блоки временного внимания.
* **Компоненты сети:**
  * Spatio-Temporal Attention: моделирует взаимосвязь между последовательными микросаккадами.
  * GP Personalization Module: анализирует $k$ калибровочных точек и вычисляет ковариационную матрицу погрешности для смещения индивидуальной оси взгляда.
* **Функция потерь:**
  $$\mathcal{L} = \mathcal{L}_{gaze} + \beta \mathcal{L}_{GP\_NLL},$$
  где $\mathcal{L}_{GP\_NLL}$ — отрицательное логарифмическое правдоподобие гауссовского процесса.
* **Параметры и производительность:**
  * Параметры: $24.8\text{ млн}$.
  * Задержка инференса: **$21.5\text{ мс}$** на CPU.
* **Доступность весов:** Google Drive `https://drive.google.com/drive/folders/16re0UoAnmaqQcqjXSkQ8u63iz_Tm9fwd?usp=sharing`, веса энкодера GazeCLR: `https://drive.google.com/file/d/17_BdB-mnsZEw33yaqHZxJYX8YLArfcq9/view?usp=drive_link`.

## 5. FAZE (Park et al., ICCV 2019 / GitHub: `NVlabs/FAZE`)

```
[Вход: Кадр лица + k калибровочных кадров]
                    │
                    ▼
[Disentangling Encoder-Decoder (DT-ED)]
  ├── Латентный вектор направления взгляда z_g
  └── Латентный вектор идентичности/света z_a
                    │
                    ▼
[MAML Meta-Learning Adaptation Head] (3 шага градиента)
                    │
                    ▼
        [Калиброванные углы (Yaw, Pitch)]
```

* **Ранг по метрике:** 5.
* **Метрика качества:**
  * Персонализированная ошибка на GazeCapture при $k=3$ кадрах калибровки: **$\mathcal{E}_{ang} = 3.18^\circ$** (при нулевой калибровке: $4.26^\circ$).
  * MPIIFaceGaze: $3.41^\circ$.
* **Размер датасета обучения:** GazeCapture ($2\,445\,504$ кадра, $1\,474$ человека).
* **Схема исполнения:** Трехстадийная архитектура ($N=3$).
* **Число стадий:** 3:
  1. *Стадия 1 (DT-ED):* Разделение представлений внешности и направления взгляда через автоэнкодер.
  2. *Стадия 2 (MAML Meta-Learning):* Обучение инициализации мета-весов, позволяющих адаптироваться к человеку за 3 шага градиентного спуска.
  3. *Стадия 3 (Few-shot Personalization):* Сессионная калибровка на $3-9$ точках экрана.
* **Входное пространство:** Кропы глаз $60 \times 90 \times 3$, нормализованные в каноническую систему камеры.
* **Бэкбон:** Модифицированный ResNet-18 со сжатыми латентными факторами $\mathbf{z}_g \in \mathbb{R}^{16}$, $\mathbf{z}_a \in \mathbb{R}^{64}$.
* **Функция потерь:**
  $$\mathcal{L} = \mathcal{L}_{meta} + \lambda_{reg}\|\theta - \theta_0\|^2.$$
* **Параметры и производительность:**
  * Параметры: $12.4\text{ млн}$.
  * Задержка инференса: **$11.5\text{ мс}$** на CPU.
* **Доступность весов:** Открытые чекпоинты на GitHub `NVlabs/FAZE`.

## 6. MediaPipe Iris + FaceMesh (Google Research, 2020 / MediaPipe 0.10)

```
[Входной кадр веб-камеры]
          │
          ▼
 [Стадия 1: BlazeFace Detector] ──► [Bounding Box лица]
                                            │
                                            ▼
           [Стадия 2: FaceMesh 3D] ──► [468 3D-лендмарок лица + Поза головы PnP]
                                            │
                                            ▼
              [Стадия 3: Iris U-Net] ──► [Кроп глаза 64x64] ──► [5 точек радужки]
                                                                        │
                                                                        ▼
                                                   [Анализ смещения центра зрачка]
                                                   [Пересечение 3D-луча с экраном]
```

* **Ранг по метрике:** 6.
* **Метрика качества:**
  * Эмпирический бенчмарк 9 сессий: **$\mathcal{E}_{ang} = 3.64^\circ \pm 0.75^\circ$** (Медиана **$3.51^\circ$**).
  * Корреляция: **$R_x = +0.945$**, **$R_y = +0.702$**, $R^2 = +0.655$.
  * Ошибка на экране: **$38.2 \pm 7.9\text{ мм}$** (**$365.4 \pm 75.3\text{ px}$**).
  * Геометрическая точность: $3.80^\circ$.
* **Размер датасета обучения:** Внутренний датасет Google ($50\,000$ размеченных лиц + $10\,000$ ручных разметок контуров радужки).
* **Схема исполнения:** Каскадная трехстадийная архитектура ($N=3$).
* **Число стадий:** 3:
  1. *Стадия 1:* Детектор лиц BlazeFace (Single-Shot Mobile Detector, якорные рамки).
  2. *Стадия 2:* Регрессор сетки лица 468 3D-точек (FaceMesh) на базе MobileNet.
  3. *Стадия 3:* Сегментатор радужки Iris U-Net (кропы $64 \times 64$, предсказывающие 5 опорных точек радужки и зрачка).
* **Входное пространство:** Произвольный RGB-кадр с веб-камеры ($640 \times 480 \dots 1920 \times 1080$).
* **Бэкбон:** Каскад легковесных сетей MobileNetV1/V2 с факторизованными свертками Depthwise Separable Convolutions.
* **Вычисление вектора:**
  $$\mathbf{d}_{iris} = \mathbf{p}_{center} - \mathbf{p}_{eyeball\_center}, \quad \mathbf{g}_{cam} = \mathbf{R}_{head} \cdot \mathbf{d}_{iris}.$$
* **Параметры и производительность:**
  * Суммарный объем весов: **$4.0\text{ млн}$** параметров.
  * Задержка инференса: **$14.97\text{ мс}$** на CPU (однопоточный запуск).
* **Доступность весов:** Встроенный скомпилированный бинарник Google TFLite / C++ библиотека MediaPipe.

## 7. UniGaze-Base (WACV 2025 / HF: `UniGaze/UniGaze-models`, Август 2025)

```
[Вход: Кадр лица 224x224x3]
```
