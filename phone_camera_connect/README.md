# Модуль захвата видеопотока с Samsung Galaxy S25 Ultra для моделей компьютерного зрения (ВКР)

Данная директория (`phone_camera_connect`) содержит программный комплекс для низколатентного захвата видеопотока с камер смартфона Samsung Galaxy S25 Ultra (SM-S938x) по кабелю USB-C и передачи несжатых BGR-кадров напрямую в память на вход моделям компьютерного зрения (CV).

---

## 1. Аппаратная топология сенсоров камеры Samsung Galaxy S25 Ultra

В спецификации смартфона Samsung Galaxy S25 Ultra установлены следующие сенсоры:

### 1.1. Фронтальный блок
* **Количество физических сенсоров:** **Строго 1 сенсор**.
* **Матрица:** 12 Мп ($4000 \times 3000$ пикселей), оптический формат $1/3.2^{\prime\prime}$, размер пикселя $1.12\,\mu\text{m}$.
* **Оптика:** Диафрагма $f/2.2$, эквивалентное фокусное расстояние $26\text{ мм}$ (угол обзора $80^\circ$).
* **Фокусировка:** Dual Pixel PDAF.
* **Примечание:** Вторичного физического фронтального сенсора на устройстве нет. Запрос на «одновременный доступ к нескольким фронтальным камерам» физически не реализуем в виде двух разных фронтальных объективов. Доступны три альтернативных режима:
  1. **Фронтальная + Тыловая камера (Dual Camera Concurrent Streaming):** Аппаратный ISP Qualcomm Spectra поддерживает одновременный опрос логической фронтальной камеры (`Camera ID 1`) и логической тыловой камеры (`Camera ID 0`) через метод Camera2 API `CameraManager.getConcurrentCameraIds()`.
  2. **Две тыловые камеры одновременно:** Например, Сверхширокоугольная ($13\text{ мм}$, $120^\circ$) + Основная ($24\text{ мм}$).
  3. **Мульти-поток с одного физического фронтального сенсора:** Формирование двух виртуальных потоков разного масштаба (полнолицевой $1920 \times 1080$ и изолированный кроп области глаз $640 \times 640$) из единого сеанса `CameraCaptureSession`.

### 1.2. Тыловой блок (4 физических сенсора)
1. **Основной широкоугольный (Main Wide, ID 0):** 200 Мп (ISOCELL HP2, $1/1.3^{\prime\prime}$, $0.6\,\mu\text{m}$, $f/1.7$, $24\text{ мм}$, OIS).
2. **Перископический телефото 5x (Periscope Telephoto, ID 1):** 50 Мп (Sony IMX854, $1/2.52^{\prime\prime}$, $0.7\,\mu\text{m}$, $f/3.4$, $115\text{ мм}$, OIS).
3. **Телефото 3x (Telephoto, ID 2):** 10 Мп (Sony IMX754, $1/3.52^{\prime\prime}$, $1.12\,\mu\text{m}$, $f/2.4$, $67\text{ мм}$, OIS).
4. **Сверхширокоугольный (Ultra-Wide, ID 3):** 50 Мп (ISOCELL JN3, $1/2.5^{\prime\prime}$, $0.7\,\mu\text{m}$, $f/1.9$, $13\text{ мм}$, $120^\circ$).

## 2. Диагностика текущего режима подключения (USB MTP)

При текущем подключении смартфона в режиме **«Android Auto / Передача файлов»** операционная система Windows регистрирует устройство:
* **Аппаратный идентификатор:** `USB\VID_04E8&PID_6860\R5GYA03715A`
* **Дочерний класс:** `WPD` (Windows Portable Device) через протокол MTP (Media Transfer Protocol).

### Причина невозможности видеозахвата в MTP:
Протокол MTP предназначен исключительно для асинхронной блочной передачи файлов (PTP-расширение). В дескрипторах интерфейса MTP отсутствуют изохронные конечные точки (Isochronous Endpoints) и дескрипторы классов UVC (USB Video Class). Ни DirectShow, ни Media Foundation, ни OpenCV не видят видеокамеру в режиме MTP.

## 3. Режимы активации видеопотока

### Режим А (Рекомендуемый для ВКР): Прямой доступ через ADB и scrcpy
Обеспечивает аппаратное аппаратное сжатие H.264/H.265 через `MediaCodec`, задержку $\approx 30\text{--}45\text{ мс}$ при 60 FPS и возможность одновременного запуска нескольких потоков.

**Шаги активации на телефоне:**
1. Открыть **Настройки** $\to$ **Сведения о телефоне** $\to$ **Сведения о ПО**.
2. Быстро нажать 7 раз на пункт **«Номер сборки»** (включится режим разработчика).
3. Вернуться в **Настройки** $\to$ **Параметры разработчика**.
4. Включить тумблер **«Отладка по USB»** (USB Debugging).
5. При подключении к ПК на экране появится окно: «Разрешить отладку по USB с этого компьютера?». Отметить галочку «Всегда разрешать» и нажать **«Разрешить»**.

### Режим Б: UVC Веб-камера (Встроенная функция Android 14/15 One UI)
Обеспечивает подключение телефона как стандартной веб-камеры Windows без установки дополнительного ПО.
1. Опустить шторку уведомлений Android.
2. Нажать на уведомление **«Зарядка через USB / Передача файлов»**.
3. В списке опций выбрать **«Веб-камера»** (Webcam).
4. Windows зарегистрирует устройство в классе `Camera`. Захват выполняется через `cv2.VideoCapture(index, cv2.CAP_MSMF)`.
*Ограничение режима Б:* Передается строго 1 видеопоток (переключение между фронтальной и тыловой камерой выполняется вручную в интерфейсе телефона).

## 4. Состав модулей в папке `phone_camera_connect`

* **`tools/`**: Встроенный комплект бинарных утилит:
  * `adb.exe` (v1.0.41, сборка 37.0.1) — мост отладки Android.
  * `scrcpy.exe` (v5.0.1) + `scrcpy-server` — высокопроизводительный движок захвата Camera2 API.
  * Библиотеки FFmpeg (`avcodec-63.dll`, `avformat-63.dll`, `avutil-61.dll`).
* **`device_detector.py`**: Утилита комплексной диагностики PnP-устройств, статуса ADB и сенсоров.
* **`scrcpy_stream.py`**: Движок низколатентного декодирования H.264/H.265 видеопотока с камеры телефона в память (NumPy BGR24) через PyAV с вытесняющим потокобезопасным буфером.
* **`uvc_stream.py`**: Движок захвата с UVC-камер через `cv2.CAP_MSMF` с фоновым тредом очистки очереди кадров.
* **`multi_camera_manager.py`**: Координатор многокамерного захвата с контролем рассинхронизации $\Delta t_{\text{sync}} = |t_1 - t_2|$.
* **`dual_rear_camera_view.py`**: Интерактивное графическое окно одновременной визуализации двух параллельных видеопотоков тыловой оптической системы: широкоугольного обзора ($24\text{ мм}$) и телефото-области ($67\text{ мм}$ / $2.5\times$).
* **`test_rear_cameras.py`**: Тестовый скрипт проверки аппаратного конфликта независимых сессий тыловых камер (Camera 0 vs Camera 2).
* **`demo_cv_pipeline.py`**: Сквозной демонстрационный конвейер детекции лиц и ключевых ориентиров (YuNet ONNX) с измерением сквозного времени отклика и FPS.

## 5. Примеры использования

### 5.1. Диагностика подключения
```powershell
& "C:\Users\jack_\MAIN\Programms\Python 3.11.9\python.exe" device_detector.py
```

### 5.2. Опрос доступных камер телефона (после включения отладки по USB)
```powershell
& "tools\scrcpy.exe" --video-source=camera --list-cameras
```

### 5.3. Запуск инференса CV-модели на фронтальной камере телефона (scrcpy)
```powershell
& "C:\Users\jack_\MAIN\Programms\Python 3.11.9\python.exe" demo_cv_pipeline.py --mode scrcpy --camera-id 1 --width 1920 --height 1080 --fps 60
```

### 5.4. Запуск CV-инференса в UVC режиме (Веб-камера Samsung)
```powershell
& "C:\Users\jack_\MAIN\Programms\Python 3.11.9\python.exe" demo_cv_pipeline.py --mode uvc --uvc-index 1 --width 1920 --height 1080
```
